# Exported Mirth channels

Add your exported channel definitions here as `.xml`.

**How to export from Mirth:** in the Administrator, right-click a channel (or select it on the
Channels screen) -> **Export Channel** -> save the `.xml` file into this folder. Suggested names:

- `HL7_File_Demo.xml`      (HL7 inbound -> transform -> SQL / FHIR)
- `FHIR_HTTP_In.xml`       (FHIR inbound over HTTP)

Exporting the channel XML lets anyone import and inspect exactly how the interface is configured.
